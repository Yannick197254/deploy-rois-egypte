1. Créer votre première base de généalogie

Cette application ne stocke rien elle-même : vos données vivent dans votre propre projet Supabase (gratuit), séparé et privé. Suivez ces étapes une seule fois pour tout mettre en place.

  1. Créez un compte gratuit sur supabase.com (bouton « Start your project »), puis créez un nouveau projet. (Un compte gratuit permet 2 projets — gardez ça en tête si vous comptez créer plusieurs arbres, voir section 6 ci-dessous.)
  2. Une fois le projet créé, ouvrez le menu SQL Editor dans la barre latérale gauche (icône en forme de tableau/base de données) — un éditeur vide s'ouvre automatiquement, prêt à recevoir le script.
  3. Copiez le script ci-dessous (bouton « Copier »), collez-le dans l'éditeur, puis cliquez sur Run. Cela crée en une fois les 3 tables nécessaires (personnes, mariages, filiations).
-- ============================================================
-- Script de création des tables — Généalogie familiale
-- ============================================================
-- MODE D'EMPLOI :
-- 1. Ouvrez votre projet sur https://supabase.com
-- 2. Dans le menu de gauche, cliquez sur "SQL Editor" (un éditeur vide s'ouvre)
-- 3. Collez tout ce fichier, puis cliquez sur "Run"
-- Les 3 tables sont créées en une seule fois.
-- ============================================================

create extension if not exists "pgcrypto";

-- Table des personnes -------------------------------------------------
create table if not exists personnes (
  id uuid primary key default gen_random_uuid(),
  nom text not null,
  prenom text,
  autres_prenoms text,
  sexe text,
  date_naissance text,
  date_deces text,
  ville_naissance text,
  pays_naissance text,
  commentaire_1 text,
  commentaire_2 text,
  commentaire_3 text,
  created_at timestamptz default now()
);

-- Table des mariages ----------------------------------------------------
create table if not exists mariages (
  id uuid primary key default gen_random_uuid(),
  personne_1_id uuid not null references personnes(id) on delete cascade,
  personne_2_id uuid not null references personnes(id) on delete cascade,
  ordre integer,
  date_debut text,
  date_fin text,
  commentaire text,
  created_at timestamptz default now()
);

-- Table des filiations ----------------------------------------------------
-- (un enfant n'a qu'une seule ligne de filiation, d'où "unique")
create table if not exists filiations (
  id uuid primary key default gen_random_uuid(),
  enfant_id uuid not null unique references personnes(id) on delete cascade,
  pere_id uuid references personnes(id) on delete set null,
  mere_id uuid references personnes(id) on delete set null,
  pere_incertain boolean default false,
  mere_incertaine boolean default false,
  created_at timestamptz default now()
);

-- ============================================================
-- Sécurité (RLS)
-- ============================================================
-- Supabase active la sécurité au niveau des lignes par défaut, ce qui
-- bloque tout accès tant qu'aucune règle n'est définie. Ces règles
-- autorisent l'app (via la clé "publishable") à lire/écrire librement —
-- adapté à un usage personnel où chaque utilisateur a son propre projet.

alter table personnes enable row level security;
alter table mariages enable row level security;
alter table filiations enable row level security;

create policy "Accès complet personnes" on personnes
  for all using (true) with check (true);

create policy "Accès complet mariages" on mariages
  for all using (true) with check (true);

create policy "Accès complet filiations" on filiations
  for all using (true) with check (true);
  1. Dans la barre latérale de gauche, cliquez sur « Integrations », puis sur « Data API » (onglet « Overview »). Vous y trouverez le champ « API URL » — copiez-le (si vous gardez par erreur le /rest/v1/ à la fin, l'application le retire automatiquement, pas d'inquiétude).
  2. Cliquez ensuite sur « Project Settings » (icône ⚙ tout en bas de la barre latérale), puis sur « API Keys ». Dans la section « Publishable key », copiez la clé qui commence par sb_publishable_.
  3. Revenez sur cette page, cliquez sur « ⚙ Changer de connexion » en haut, et collez ces deux valeurs. (Cette fenêtre peut être fermée à tout moment via le « × » si vous voulez d'abord relire ce guide.)

2. Comment fonctionne cette application

Elle ne stocke rien elle-même : elle se contente d'afficher et de modifier les données de votre projet Supabase.

  • La connexion (URL + clé) que vous saisissez est mémorisée dans ce navigateur, sur cet appareil — pas de compte, pas de mot de passe à ce niveau-là.
  • Sur un autre navigateur ou un autre appareil, vous devrez saisir à nouveau ces deux valeurs (elles restent disponibles sur la page « API Keys »/« Data API » de votre projet Supabase, à tout moment).
  • En navigation privée, rien n'est mémorisé : il faut se reconnecter à chaque session.
  • L'application n'est connectée qu'à un seul arbre à la fois — voir la section 6 pour en gérer plusieurs.

3. Encoder vos données

Trois onglets en haut : Personnes, Mariages, Filiations. Ajoutez d'abord les personnes, puis reliez-les par des mariages et des filiations (chaque enfant n'a qu'une seule fiche de filiation, avec un père et/ou une mère — laissez sur « ? » si inconnu, ou cochez « incertain·e » si le lien est probable mais pas garanti).

Suppression : elle est définitive et immédiate — il n'y a pas de corbeille dans cette version. Pensez à exporter régulièrement (section 4) si vous voulez pouvoir revenir en arrière en cas d'erreur.

4. Sauvegarder vos données

Le bouton « 💾 Sauvegarder en Excel » télécharge un fichier .xlsx avec vos 3 tables. C'est à la fois une sauvegarde à conserver de votre côté et un fichier réimportable (section 5) — utile avant une suppression importante, ou pour transférer vos données vers un autre arbre.

5. Réimporter des données

Le bouton « 📥 Importer depuis Excel » accepte un fichier généré par « Sauvegarder en Excel » (ci-dessus) sur cette application, ou par l'export d'une autre installation compatible.

  • L'import ajoute les données à celles déjà présentes — il ne vide pas la base avant.
  • Si les fiches du fichier existent déjà dans la base connectée (mêmes identifiants), l'import est bloqué avec un message clair — aucun doublon n'est créé par erreur.
  • Pour importer dans une base neuve, assurez-vous qu'elle est bien vide au préalable (nouveau projet tout juste créé, section 1).

6. Créer ou gérer plusieurs arbres

Le bouton « 🌳 Mes arbres » en haut liste tous les arbres auxquels vous vous êtes déjà connecté·e sur ce navigateur, avec un nom que vous choisissez — cliquez sur « Utiliser » pour basculer instantanément de l'un à l'autre, sans ressaisir l'URL/clé à chaque fois.

Pour ajouter un nouvel arbre à la liste :

  1. Créez un nouveau projet Supabase séparé et exécutez-y le script SQL (section 1, étapes 1 à 3).
  2. Cliquez sur « ⚙ Changer de connexion » et saisissez l'URL/clé de ce nouveau projet. Un nom vous sera demandé — il apparaîtra ensuite dans « Mes arbres ».

Deux limites différentes à ne pas confondre :

  • Cette application peut mémoriser autant d'arbres que vous voulez — aucune limite de son côté.
  • Supabase, lui, limite un compte gratuit à 2 projets actifs. Pour un 3e arbre gratuit, il faut soit passer un projet existant en payant, soit créer un second compte/organisation Supabase (avec une autre adresse email) qui aura droit à 2 projets gratuits supplémentaires.

Chaque arbre reste intact indépendamment des autres — la liste « Mes arbres » n'est qu'un raccourci mémorisé dans ce navigateur ; « Retirer » un arbre de cette liste n'efface aucune donnée sur Supabase, juste le raccourci local.

7. Visualiser en 3D

Le lien « 🌳 Vue 3D » en haut ouvre une représentation interactive de l'arbre connecté (même connexion, pas besoin de la ressaisir). Une « vue simplifiée » est disponible pour les arbres bien fournis, et un bouton permet de générer une vue figée — un fichier autonome, centré sur une personne, à partager sans donner accès à la base complète.

8. Visualiser en 2D (schéma imprimable)

Le lien « 📐 Vue 2D » propose une représentation schématique classique (arbre à plat, sans rotation), pensée pour être imprimée ou partagée simplement. Un bouton « 🖨️ Imprimer » lance directement l'impression du schéma (l'en-tête et la légende sont automatiquement masqués à l'impression). Même connexion que le reste de l'application — pas besoin de la ressaisir.
